# A Garden for Ghala

A personal interactive birthday-gift experience built with HTML, CSS, and JavaScript.

## Project progress

### Working features
- Welcome screen and navigation into the Forgotten Forest.
- Forgotten Forest hub with two routes: Path of Light to the Lily Clearing and Path of Whispers to the Beach.
- Lily Clearing with an interactive special lily, discovery counter, message panel, and discovery journal.
- Beach scene with return navigation.
- Puzzle screen currently used as a temporary testing route.
- Leo's Hidden Clearing with return navigation and a cinematic entrance: the introductory text appears, navigation controls temporarily fade away, then return.

### Leo's Hidden Clearing — current design work
- Woodland clearing background is in place.
- Three hanging photograph positions and an enlarged-photo viewer are part of the scene structure.
- An ornate gold frame PNG and five Leo photo assets have been prepared locally.
- Planned photo assignment: use `leo-photo-actual.png` as the reference for Leo's bench model; use `leo-photo-2.png`, `leo-photo-4.png`, and `leo-photo-5.png` in the three hanging frames. `leo-photo-6.png` is an alternative.
- The gold-frame/photo sizing is intentionally left for later fine-tuning once the image assets can be inspected together.
- Leo's bench model and petting/purring interaction are not implemented yet.
