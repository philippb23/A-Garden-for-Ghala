# A Garden for Ghala

A personal interactive birthday-gift experience built with HTML, CSS, and JavaScript.

## Project progress

### Working features
- Welcome screen and navigation into the Forgotten Forest.
- Forgotten Forest hub with two routes: Path of Light to the Lily Clearing and Path of Whispers to the Beach.
- Lily Clearing with an interactive special lily, discovery counter, message panel, and discovery journal.
- Beach scene with return navigation.
- Puzzle screen currently used as a temporary testing route.
- Leo's Hidden Clearing with return navigation and a cinematic entrance: introductory text appears, navigation controls temporarily fade away, then return.
- Leo's Hidden Clearing woodland background, bench, and Leo cutout are in place.
- Leo's meow and purr interactions are implemented, including press-and-hold behavior and breathing ambience.
- Three hanging photo frames are positioned along the tree branch.
- Clicking a hanging photograph opens the enlarged-photo viewer; the viewer can be closed using its controls, the backdrop, or Escape.
- The three frame photos currently use `leo-photo-2.png`, `leo-photo-4.png`, and `leo-photo-6.png`.
- Frame sizing and photo fitting have been corrected: frames 2 and 3 preserve their full photographs with the `.photo-fit` styling.
